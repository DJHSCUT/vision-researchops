# DEMO：遮挡与 3DGS 重建缺失问题

> DEMO 知识文档：以下是用于检索的排查思路，不是实际项目诊断、科研结论、论文原文或官方规范。

## 未观察到的区域

遮挡意味着目标表面在某些相机视角中被其他物体或自身结构挡住。如果一个区域在所有采集图像中都不可见，图像通常无法提供直接的外观和几何约束。3DGS 不应被视为可以可靠恢复未观测区域真实细节的方法。视角覆盖不足和持续遮挡可能造成重建缺失、空洞，以及新视角切换时出现的错误外观或漂浮伪影。

同一侧的高重叠照片可能改善可见表面的匹配，却仍然无法约束被遮挡的背面。凹槽、薄结构、植被内部和接触面尤其需要检查可见性。补拍时应改变相机高度或方位，确认遮挡关系发生变化并且新图像与已有图像有可匹配区域。仅增加同一路径的照片密度不一定能补全缺失。

## 区分不同原因

先区分“该区域从未被看到”和“该区域被看到但重建失败”。后者可能与位姿误差、特征不足、透明或反光材质、动态物体、初始化和训练参数有关。若 COLMAP 在相关视角未成功注册，则应先检查相机估计；若位姿合理且局部图像清晰，则进一步检查优化配置和渲染结果。不要把每一种伪影都解释为遮挡。

较高的平均 PSNR 或 SSIM 不能保证不存在局部重建缺失。背景像素占比大或缺失区域较小时，均值可能仍然较高。应将指标与局部区域渲染、视角覆盖示意和相机轨迹联合分析。

## DEMO 验证方案

对疑似缺失区域记录位置、可见视角、注册状态和局部截图。补拍或修改训练参数时每次尽量只改变一个主要因素，保持测试视角可比，并记录前后差异。若无法采集额外视角，报告应明确该区域缺少观测证据；不能将推测得到的表面细节当作真实测量结果。
