# DEMO：3DGS 的 PSNR 与 SSIM 评价指标

> DEMO 知识文档：以下为检索开发的概念说明，不是论文原文、真实实验结果或官方指标规范。文中不包含项目实际指标值。

## PSNR 的含义与边界

PSNR（峰值信噪比）根据渲染图与参考图的均方误差计算，常见表达为 PSNR = 10 × log10(MAX² / MSE)。MAX 为像素取值范围的最大值；当像素归一化到 0–1 时通常取 1。均方误差为零时，理论 PSNR 为正无穷，实现需要明确这种特殊情况的处理。PSNR 常用 dB 表示，通常数值越高代表像素误差越小，但不等于更准确的几何或更完整的表面。

对 3DGS，应分别报告训练视角和保留测试视角的指标。只看训练视角可能高估新视角质量。相机参数错误、曝光差异、图像对齐误差以及背景占比都可能影响 PSNR。若使用前景掩码，需记录掩码定义和参与计算的有效像素，避免不同实验的指标实际上对应不同区域。

## SSIM 的含义与可比性

SSIM（结构相似性）结合局部亮度、对比度与结构信息。相同实现和评价设置下，较高 SSIM 通常意味着较高结构相似度。SSIM 也不能直接证明几何正确或无重建缺失；大面积背景可能掩盖局部缺陷，平滑图像也不必然具备准确细节。

比较结果时记录图像尺寸、RGB 或灰度处理、像素范围、窗口大小、实现版本和是否裁剪或使用掩码。不同实现可能包含不同边界处理或聚合方式，不能只比较指标名称。跨视角均值应明确是先逐图计算再平均，还是使用其他聚合方式；这些处理会影响结果。

## DEMO 报告建议

同时保存测试视角渲染图、参考图和局部细节检查记录，避免仅用单个均值描述质量。必要时分析低分视角及其对应遮挡区域。实验日志需将 PSNR、SSIM、数据划分、训练步数和参数版本关联到同一 Run。本文件不提供任何“达到某分数即科研成功”的判断阈值。
