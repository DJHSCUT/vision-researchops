# DEMO：COLMAP 与相机位姿

> DEMO 知识文档：本文件为本项目检索开发编写的技术示例，不是 COLMAP 官方文档、论文原文或真实实验结论。

## 从图像到相机参数

COLMAP 是常用于 Structure-from-Motion（SfM）和多视角立体视觉的工具。典型 SfM 流程包含特征提取、图像匹配、图像注册、三角化和束调整。输出可包含相机内参、图像外参及稀疏三维点。3DGS 通常利用相机参数构造训练视角，并可利用稀疏点云初始化高斯表示。相机参数质量会影响优化约束，因此“图像数量很多”不代表位姿一定可靠。

相机内参描述焦距、主点以及所选相机模型的畸变参数；外参描述三维点在坐标系之间的变换。读取 COLMAP 数据时必须区分 world-to-camera 和 camera-to-world。常见约定 x_camera = R × x_world + t 下，相机中心为 C = -Rᵀ × t，不能直接把平移向量 t 当成世界坐标中的相机位置。还需确认四元数分量顺序和坐标轴约定，避免转换出错误轨迹。

## 失败排查

重叠不足、低纹理、重复纹理、运动模糊、动态目标和强反光都可能妨碍可靠匹配。图像未注册时应查看匹配连通性及采集覆盖，而不是仅增加训练迭代。错误相机模型或不适当的内参共享设置也可能影响重建。低重投影误差是有用线索，但不能单独证明所有位姿正确。

检查相机轨迹是否符合采集路线，稀疏点是否落在合理区域，以及未注册图像是否集中在特定方位。单目 SfM 通常不能仅凭图像确定绝对尺度；与测量坐标对齐时需要额外尺度或控制信息。

## DEMO 记录建议

记录 COLMAP 版本、匹配策略、相机模型、内参设置、注册图像数量和输入图像列表。保留坐标转换代码版本和输出路径，使 3DGS 训练所用位姿可以追溯。不得在没有检查原始输出的情况下把重建缺失直接归因于 COLMAP，也不能把注册成功当作完整表面覆盖的保证。
