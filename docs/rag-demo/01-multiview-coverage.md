# DEMO：3DGS 多视角数据采集与重叠率

> DEMO 知识文档：本文件为检索开发编写的教学示例，不是论文原文、真实实验结论或官方采集规范。所有建议都需要结合实际场景验证。

## 视角覆盖不足的影响

3D Gaussian Splatting（3DGS）利用多视角图像和相机参数优化场景表示。视角覆盖不足会使部分表面缺少足够的观测约束，可能出现重建缺失、空洞、漂浮高斯、几何不稳定，以及新视角渲染中的伪影。仅从同一侧拍摄物体时，背面和凹陷区域可能从未被相机看到；增加同一角度的重复照片不能替代这些缺失视角。透明、反光和低纹理区域还可能引入额外困难，因此不能把所有缺失都归因于照片数量。

相邻图像应共享足够的可匹配纹理区域，同时具备一定视差。重叠过低可能导致特征匹配不足，影响 COLMAP 图像注册和相机位姿估计；视角几乎相同虽然重叠很高，却可能缺少有效基线。重叠率只是采集质量的一项参考，不能独立保证重建成功。可见区域重叠与特征匹配数量也不是同一个量。

## DEMO 采集检查思路

对静态对象，可沿周向采集，并在不同高度补充斜视图；检查目标顶部、底部边缘和凹陷处的可见性。尽量保持清晰对焦、稳定曝光，避免大幅运动模糊和移动物体干扰。拍摄范围、角度间隔和所需照片数依赖物体尺寸、纹理和遮挡情况，本示例不设定适用于所有场景的固定重叠率阈值。

采集后先检查图像注册比例、匹配连通性、稀疏点云分布及相机轨迹，再查看 3DGS 的新视角效果。发现局部缺失时应定位缺失表面是否实际被多个视角看到，必要时补拍；不能仅凭训练 PSNR 较高认定几何完整。评估补拍效果时应固定数据划分和训练设置，并记录新增视角覆盖了哪些区域。
